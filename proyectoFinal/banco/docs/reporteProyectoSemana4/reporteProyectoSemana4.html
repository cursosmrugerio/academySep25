✨ Características Implementadas

Gestión de Clientes

  • Registro con email único y validaciones
  • Actualización de datos personales
  • Soft delete (estados ACTIVE/INACTIVE)
  • Validación de teléfono (10 dígitos)
  • Timestamps automáticos

Operaciones Bancarias

  • Creación de cuentas (SAVINGS/CHECKING)
  • Generación automática de número de cuenta
  • Depósitos con validaciones
  • Retiros con balance mínimo (polimorfismo)
  • Transferencias transaccionales
  • Consultas por múltiples filtros

Sistema de Notificaciones

  • 9 tipos de notificaciones
  • 4 canales (EMAIL, SMS, PUSH, IN_APP)
  • Estados (PENDING, SENT, FAILED, RETRY)
  • Event-driven con Spring Modulith
  • Simulación de envíos

Procesamiento Batch

  • Job mensual de cálculo de intereses
  • Factory Pattern para calculadoras (polimorfismo)
  • SAVINGS: 5% anual (0.42% mensual)
  • CHECKING: 1% anual (0.083% mensual)
  • Chunk processing (10 cuentas por lote)
  • Logs en MongoDB

🎨 Patrones de Diseño Aplicados

  1. Strategy Pattern: InterestCalculator con múltiples implementaciones
  2. Factory Pattern: InterestCalculatorFactory para selección dinámica
  3. Repository Pattern: 5 repositories (JPA + MongoDB)
  4. DTO Pattern: Request/Response objects para APIs
  5. Event-Driven Architecture: 5 eventos + 7 listeners
  6. Template Method: Spring Batch read-process-write
  7. Chain of Responsibility: Flujo de batch steps
